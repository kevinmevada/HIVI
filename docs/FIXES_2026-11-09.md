## Found while fixing

- **`(str, Enum)` stringified wrong on Python 3.11+.** `str(ActorRole.PROJECT_OWNER)` was
  `'ActorRole.PROJECT_OWNER'`, so the ledger stored that text and owner/system events were
  retained as `unverified`. Memory enums are now `StrEnum`. Existing rows in
  `data/hivi/hivi.sqlite` and Hindsight banks keep the old strings. `test_enum_strings.py`
  fails on the old code.
- **`coli stop` never stopped anything.** It defaults to port 8000; HIVI serves on 8080.
  Now called as `coli stop --port 8080`, and only for a backend HIVI owns.
- **`/api/status` said "ready" after the engine died.** Now reports `unhealthy`.
- **Vendored Colibrì was 1.10.2; you run 2.1.0** from Downloads. The runtime rejects
  < 2.1.0 with a clear message; `fetch_backends.ps1` pins `v2.1.0`.
